```text
GUSTAFTA_API_KEY
```

Jangan pernah:

```text
React frontend → Gustafta API
```

Yang benar:

```text
React
 ↓
Gaia SIAP backend
 ↓
Gustafta /api/v1/ai/assist
```

Dengan begitu key tidak bocor ke browser.
