# Feature Request: Auto AI Assistant Generator

## Objective

Create a new feature called **"Auto AI Assistant Generator"** that allows users to transform documents stored in **Ruang Simpan** into a ready-to-use AI Assistant (Chatbot) with just a few clicks.

This feature is intended for users who do not want to manually build chatbots using the Builder.

The Builder will remain available for advanced customization.

---

# User Flow

```
Ruang Simpan
      ↓
Select Folder
      ↓
Click "Create AI Assistant"
      ↓
Wizard
      ↓
Automatic Generation
      ↓
Ready to Chat
```

# Automatic Generation Process

When user clicks Generate

Backend should automatically

1. Create Knowledge Base

2. Import every supported document

3. Extract text

4. Generate embeddings

5. Build vector index

6. Create default Persona

7. Create default System Prompt

8. Create Chatbot

9. Connect Chatbot with Knowledge Base

10. Enable citation mode

11. Publish chatbot internally

12. Return chatbot URL

Everything should happen automatically.

User should never need to manually create these components.

# Success Criteria

A non-technical user should be able to

1. Upload documents into Ruang Simpan.

2. Click "Create AI Assistant."

3. Wait less than one minute.

4. Receive a fully functional AI Assistant.

Without understanding prompts, embeddings, vector databases, or chatbot building.

This feature should position Gustafta as the easiest platform for transforming business knowledge into AI Assistants while preserving the full power of the Builder for advanced users.

## Satu tambahan yang menurut saya sangat penting

Saya akan meminta Replit **tidak membuat AI Assistant sebagai entitas yang terpisah dari Chatbot**.

Sebaliknya, AI Assistant adalah **template otomatis yang menghasilkan Chatbot**.

Secara arsitektur:

```text
Ruang Simpan
      │
      ▼
Auto AI Assistant Wizard
      │
      ▼
Automation Engine
      │
      ├── Create Knowledge Base
      ├── Create Persona
      ├── Create Prompt
      ├── Create Chatbot
      ├── Link Knowledge
      ├── Configure Defaults
      └── Publish
            │
            ▼
Existing Chatbot Engine
```

Dengan pendekatan ini, Anda **tidak perlu memelihara dua sistem berbeda** (AI Assistant dan Chatbot). AI Assistant hanyalah **cara otomatis membuat chatbot** menggunakan engine Builder yang sudah ada. Ini menjaga kode tetap sederhana, mengurangi duplikasi, dan semua peningkatan pada Chatbot Builder akan otomatis dinikmati oleh AI Assistant juga.
