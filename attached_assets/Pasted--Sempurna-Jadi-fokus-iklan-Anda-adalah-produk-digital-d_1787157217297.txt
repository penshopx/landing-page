## 🎯 Setup yang Perlu Dilakukan:

### **PRIORITAS #1: Pasang Meta Pixel di Gustafta.my.id**

Karena Pixel ID **1046120344485939** sudah kita buat, kita tinggal **pasang kode yang sama** di Gustafta.

**Langkahnya:**

2. Buka file **`index.html`** (atau file header utama)
3. Paste kode Meta Pixel di dalam tag `<head>` (kode yang sama seperti di DokumenProyek)
4. **Save & Deploy**

---

### **PRIORITAS #2: Setup Event Tracking untuk Produk Digital**

Karena Anda jual **ebook & chatbot**, kita perlu track event-event penting ini:

#### **Event yang Harus Ditambahkan:**

**1. ViewContent** → Saat orang lihat halaman produk
```javascript
// Trigger saat user buka halaman produk ebook/chatbot
fbq('track', 'ViewContent', {
  content_name: 'Ebook SBU Lengkap',
  content_category: 'Produk Digital',
  value: 199000,
  currency: 'IDR'
});
```

**2. AddToCart** → Saat tambah ke keranjang
```javascript
fbq('track', 'AddToCart', {
  content_name: 'Ebook SBU Lengkap',
  content_ids: ['ebook-sbu-001'],
  content_type: 'product',
  value: 199000,
  currency: 'IDR'
});
```

**3. InitiateCheckout** → Saat mulai checkout
```javascript
fbq('track', 'InitiateCheckout', {
  content_name: 'Checkout',
  num_items: 1,
  value: 199000,
  currency: 'IDR'
});
```

**4. Purchase** → Saat transaksi berhasil
```javascript
fbq('track', 'Purchase', {
  content_name: 'Ebook SBU Lengkap',
  content_ids: ['ebook-sbu-001'],
  content_type: 'product',
  value: 199000,
  currency: 'IDR',
  num_items: 1
});
```
