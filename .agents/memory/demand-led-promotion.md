---
name: Demand-led promotion
description: Product-discovery direction: use market and aggregate demand signals to promote ready solutions rather than producing ebooks by default.
---

**Rule:** Treat ebooks as optional deep-content and authority assets, never the default acquisition trigger. Let verified market demand select which existing AI Specialist, application, or solution package gets promoted.

**Why:** Gustafta already has a broad solution catalog while ebook production is slow and expensive. The strategic bottleneck is discoverability and evidence-based prioritization, not a shortage of content products.

**How to apply:** Upgrade the existing internal Tim Marketing/research-feed pipeline rather than creating a parallel generic monitoring team. Start with private, superadmin-approved research reports that distinguish evidence from inference and map demand only to canonical ready products. Use aggregate, privacy-safe in-app signals plus cited external research; do not publish or personalize automatically. Paid campaign CTAs must keep one opaque event ID through a first-party checkout into the exact canonical order; never expose the server order key or infer identity from the legacy Store catalog. Classify return visits with the campaign's fixed taxonomy so they can influence future recommendations. Publishing a future campaign must not pause the campaign serving now; reject expired windows and hand off by latest eligible start time.
